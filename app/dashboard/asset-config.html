Page Purpose

This page serves as the central specification and regulatory rules engine for your fleet. The technical rules, fluid capacities, PM thresholds, and parts cross-references configured here build the exact mobile inspection checklists (DVIR), preventative maintenance alerts, and inventory lookup tables used by drivers, operators, and mechanics in the field.

How to Use This Page

  1. Select Target Level: Choose Category Global Defaults to define baseline rules for an entire equipment class (e.g., Dozers), or Specific Asset Unit Overrides to configure an individual unit (e.g., DZ-101).
  2. Enable Override: When configuring a specific unit, toggle "Override Category Global Defaults" to unlock form fields for editing.
  3. Configure Overlays & Attachments: Select vocational bodies (e.g., Hydro-Vac, Crane, Mixer) to automatically append component checks and fluid capacities.
  4. Enter Technical Specs & Parts: Input powertrain specs, fluids, and filter part numbers. Use aftermarket cross-references to simplify shop replacements.
  5. Save Configuration: Click "Save Complete Asset Configuration" to lock in rules across driver mobile apps and maintenance dashboards.
