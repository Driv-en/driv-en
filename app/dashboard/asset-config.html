Purpose & Page Instructions

This page acts as the central master configuration engine for your fleet. The settings and specifications configured here build the exact inspection checklists (DVIR), PM maintenance triggers, parts cross-referencing, and telematics thresholds across your entire system.

How to Use This Page:

  1. Choose Target Level: Select Category Global Defaults to set standard baseline rules for an entire equipment class (e.g., Dozers), or Specific Asset Unit Overrides to customize a single unit (e.g., DZ-101).
  2. Enable Override: When configuring a specific unit, toggle "Override Category Global Defaults" to unlock all fields for editing.
  3. Select Attachments: Attach vocational bodies (e.g., winches, rippers, cranes) to dynamically load required specs like cable size and winch ratings.
  4. Configure Technical Specs & Parts: Fill in powertrain, fluids, filters (air/cabin), and cross-referenced replacement parts. Dropdowns feature a "+ Add Custom Option..." feature if a spec isn't listed.
  5. Save Configuration: Click "Save Complete Asset Configuration" to lock in rules for driver inspections and PM alerts.
