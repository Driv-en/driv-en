📋 Bulk Tank Setup Requirements: When adding a bulk storage tank, ensure the following information is entered:
  • Fluid Type — Gasoline, Diesel (On-Road), Diesel (Off-Road), DEF, Propane, or any other fluid the customer wants to monitor
  • Capacity — Total tank capacity in gallons
  • Asset # — Unique identifier for the tank
  • Current Quantity — How much fuel is currently in the tank
  • Current Location — Where the tank is physically located
⚠️ Portable Gas Can Lifecycle: During project setup, a portable gas can is created with the project number as part of the asset number (e.g., Gas Can – Location #). Only one can per project is needed — even if filling 5 cans at once, there is no reason to issue each can a number. When the project is complete, this asset MUST be removed from the gas can list. Ensure this step is not skipped during project closeout.
