data-model-validation.md (v1.0)
Purpose
Ensures all core tables in Driv en v1.0 match the required structure for PM workflows, dashboards, role boundaries, and automations. This file is authoritative. No other file may override these rules.
1. Equipment Table Validation
Required Relationships
•	Must link to:
o	Equipment Specs
o	PM Schedule (auto-generated)
o	PM Completion (auto-generated)
o	PM Templates (auto-generated)
o	PM Families
o	PM Family Type Map
o	Record Index
o	Division
o	Assigned Technician
o	Assigned Operator
Required Fields
•	Equipment ID (formula)
•	Equipment Name
•	Equipment Type
•	Division
•	Status
•	Meter Type
•	Meter Reading
•	Sync metadata fields
•	Backlinks to all PM tables
Validation Rules
•	No customer-facing access
•	No role except Admin may edit
•	All dashboards read-only except Admin
2. Equipment Specs Table Validation
Required Fields (1–34 locked)
•	All fields exactly as provided in the v1.0 schema
•	DEF Type removed
•	DEF Capacity retained
•	All lookup fields must resolve correctly from Equipment
•	All spec fields must be read-only for non-admin roles
Validation Rules
•	Must support Technician and Operator read-only views
•	Must support Admin editing
•	Must support PM Template lookups
3. PM Families Table Validation
Required Fields (1–17 locked)
•	Default Interval
•	Default Meter Type
•	Default Meter Threshold
•	Sync metadata
•	Backlinks to PM Family Type Map
•	Backlinks to PM Templates (auto-generated)
Validation Rules
•	Must support PM Template generation
•	Must support PM Schedule generation
•	Must support override logic
4. PM Family Type Map Table Validation
Required Fields (1–20 locked)
•	Override Interval
•	Override Meter Threshold
•	Default Interval (lookup)
•	Default Meter Threshold (lookup)
•	Equipment Type
•	PM Family
•	Sync metadata
Validation Rules
•	Must support PM Template generation
•	Must support PM Schedule generation
•	Must support override-first logic
5. PM Templates (auto-generated) Table Validation
Required Fields (locked)
•	PM Template ID
•	PM Family
•	Equipment Type
•	Interval
•	Meter Threshold
•	Sync metadata
•	Backlinks to PM Schedule
•	Backlinks to PM Completion
Validation Rules
•	Must be generated by the “Generate PM Template” automation
•	Must support Technician PM completion
•	Must support Manager/Foreman read-only views
6. PM Schedule (auto-generated) Table Validation
Required Fields (locked)
•	PM Schedule ID
•	Equipment
•	PM Template
•	Next Due Date
•	Next Meter Threshold
•	Sync metadata
•	Backlinks to PM Completion
Validation Rules
•	Must be generated by PM Template logic
•	Must support Technician PM completion
•	Must support Manager/Foreman read-only views
7. PM Completion (auto-generated) Table Validation
Required Fields (1–49 locked)
•	All fields exactly as provided in the v1.0 schema
•	Meter Reading
•	Photos
•	Notes
•	Damage Report
•	Safety Issue Report
•	Sync metadata
•	Backlinks to Equipment
•	Backlinks to PM Schedule
•	Backlinks to PM Template
Validation Rules
•	Only Technicians may complete PMs
•	All other roles read-only
•	Must support PM Schedule updates
•	Must support PM Template relationships
