# Projects (Supporting Data — v1.0)

## Purpose
Projects exist ONLY to:
- Assign equipment to a location
- Filter PMs and inspections
- Provide basic reporting context

## Required Fields
- Project Name
- Division
- Client (optional)
- Status (Active / Inactive)

## Rules
- Projects are NOT a module
- No scheduling, tasks, budgets, or workflows
- Equipment assignment updates Equipment Location
