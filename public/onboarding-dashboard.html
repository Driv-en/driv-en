Step 7 — Projects
Projects
Add active, recently completed, or upcoming projects. You will need: project number, project name, physical address of the project, client, division, project type, project manager, and superintendent. Each project references Employees (Step 3), Clients (Step 4), Divisions (Step 5), and Project Types (Step 6) — those must be completed first. Even company-owned facilities (e.g., "Yard #1") should be assigned a project name so all equipment locations can be tracked.
