How to use this template:
1. Update the <title> and SEO meta tags in the <head>
2. Replace this content box with your page content
3. Add page-specific styles in the PAGE-SPECIFIC STYLES section above
4. Do NOT remove the SHARED STYLES, header, footer, or script tags
5. Use <span class="brand-driv">DRIV</span><span class="brand-dash">‑</span><span class="brand-en">EN</span> for branded text
6. Use <img src="/logo.png?v=2" class="inline-logo"> for inline logos
7. Bump ?v numbers on CSS/JS links when those files are updated
8. The mobile nav, header, and footer are automatic — do not add them manually
